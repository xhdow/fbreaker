
# 项目概述
本程序的功能是快速、批量地破坏文件原数据，使其不能正常使用，以达到保护隐私的目的。在需要有时候，可以恢复原文件数据结构。
具体的算法有不同版本，详见后续章节。



# 算法
## 版本 V1
- 将文件头fminsize个字节（默认为64字节）逐个与密码的第1个字节异或运算，然后写回原文件。
- 在加密后的文件末尾依次插入以下内容：

|Offset|Length|Type|Value|
|----|----|----|----|
|*|16|bytes|password md5（用于验证密码是否正确）|
|*|*|bytes|utf8 encoded string|
|-8|4|int|big edian int value|
|-4|4|str|XXXX（用于标识加密版本，或判断文件是否己加密）|
